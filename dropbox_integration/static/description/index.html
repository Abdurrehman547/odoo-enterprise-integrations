Key Features

Automated Folder Creation

Create dedicated Dropbox folders with a single click directly from contact and business records.

1-Click Shareable Links

Folders are automatically assigned shared link access, and the direct URL is stored on the record.

Standalone & Independent

1. Configuration & Setup in Settings

Navigate to Settings > General Settings > Integrations > Dropbox. Enable the Dropbox toggle, enter your Dropbox App Key, App Secret, and optional Root Folder Path (e.g. /Odoo_Uploads), then click Setup Access Token to authorize.

Settings Panel: Configure Dropbox App Key, Secret, Root Folder Path, and launch authorization

2. Create Dropbox Folder on Contacts

Open any Customer or Contact form. In the form header, click the highlighted button Create Dropbox Folder. The direct Dropbox Folder Link field is conveniently available on the contact details.

Contact Form: Header action button and shareable Dropbox Folder Link field

3. Add Folder Name & Create

A clean popup wizard appears with the contact name pre-populated. Confirm or customize the folder name and click Create Dropbox Folder to generate the cloud folder and attach the shareable URL.

Creation Dialog: Enter/confirm the folder name to automatically create in Dropbox

4. Linked Contact with Smart Button & Live Dropbox Link

Once the folder is created, the dedicated Dropbox smart stat button appears at the top of the contact form for instant access. The live, shareable Dropbox Folder Link is populated directly on the record for seamless team collaboration.

Connected Record: Top smart stat button for 1-click cloud access and direct live Dropbox folder URL
