Key Features

Automated Folder Creation

Create dedicated Google Drive folders with a single click directly from contact and partner records.

1-Click Shareable Links

Generated folders are assigned view permissions and the web link is saved directly on the record.

OAuth 2.0 Web Auth

Secure web authorization flow with CSRF state protection, offline refresh tokens, and automatic token refresh.

Standalone & Independent

Depends strictly on standard Odoo core (base, base_setup) without hardcoded business module locks.

1. Configuration & Setup

Navigate to Settings > General Settings > Integrations > Google Drive. Enable Google Drive, enter your Google OAuth credentials, and click Connect to Google Drive to authorize.

Google Drive settings panel in Odoo General Settings with credentials and authorization button

2. Create Google Drive Folder on Contacts

Open any Customer or Contact record. Click the prominent Create Google Drive Folder button located conveniently in the form header.

Contact form view featuring the "Create Google Drive Folder" header action button

3. Add Folder Name & Create

A clean popup wizard appears with the contact's name pre-populated. Confirm or customize the folder name and click Create Folder to generate the cloud folder instantly.

Folder creation wizard dialog allowing users to confirm the Google Drive folder name
